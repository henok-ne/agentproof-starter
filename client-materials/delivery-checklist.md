# QA Sprint Delivery Checklist

## Before testing

- Scope confirmed.
- Written authorization received.
- Test environment confirmed.
- Data access minimized.
- Expected behavior documented.
- Deadline confirmed.
- Payment terms confirmed.

## During testing

- Test cases created.
- Normal workflows tested.
- Edge cases tested.
- Unsupported questions tested.
- Privacy boundaries tested.
- Tool actions tested only within authorization.
- Findings reproduced.
- Severity assigned consistently.

## Before delivery

- Findings reviewed.
- Sensitive data removed from report.
- Regression tests included.
- Recommendations written clearly.
- Loom walkthrough recorded.
- Customer handoff scheduled.

## After delivery

- Customer confirms receipt.
- Testimonial requested only if appropriate.
- Follow-up retest offered.
- Repeated patterns added to AgentProof playbook.

## Test categories

- Happy-path user journeys
- Unsupported questions
- Ambiguous requests
- Contradictory information
- Multi-turn conversations
- Retrieval and grounding
- Prompt and instruction injection
- Privacy boundaries
- Authorization boundaries
- Tool and workflow actions
- Error handling
- Regression cases

## Test record

For each test, record:

- Test ID
- Category
- User input
- Conversation history
- Expected behavior
- Actual response
- Retrieved context, if available
- Model and prompt version, if available
- Pass/fail
- Severity
- Reproduction steps
- Recommended fix

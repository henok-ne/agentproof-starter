# AgentProof Data Handling

AgentProof will test only systems and data that the customer authorizes in
writing.

Customers should provide:

- A staging environment.
- Synthetic data.
- A dedicated test account.
- Redacted sample conversations.
- Limited-scope API credentials, if needed.

Customers should not provide production passwords, unrestricted access tokens,
payment details, or unnecessary personal information.

AgentProof will not publish customer data, screenshots, transcripts, or
findings without written permission.

The customer remains responsible for production deployment decisions.

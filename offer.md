# AgentProof AI Assistant QA Sprint

## We test AI products before their users do.

AgentProof helps AI and SaaS teams find unreliable answers, unsupported claims,
broken workflows, privacy failures, and prompt regressions before release.

## Best fit

This service is for teams shipping:

- AI customer-support assistants
- Knowledge-base and RAG assistants
- SaaS copilots
- Internal AI assistants
- Tool-using AI agents

The best first customers are small and growing teams that do not yet have a
specialist AI QA function.

## What we test

A QA Sprint can include:

- Realistic user journeys
- Unsupported and ambiguous questions
- Hallucination and grounding behavior
- Retrieval and knowledge-base behavior
- Multi-turn conversations
- Prompt and instruction injection
- Privacy and authorization boundaries
- Unauthorized actions
- Regression after prompt or model changes

## What you receive

Within five business days, AgentProof delivers:

- Test plan for one AI feature
- Up to 50 product-specific scenarios
- Failure transcripts and reproduction steps
- Severity-ranked issue report
- Recommended fixes
- Regression test pack
- Recorded results walkthrough

## Founding-customer price

$400 for the first three customers.

The price covers one AI feature, one authorized test environment, and one
written report.

## Customer requirements

The customer must provide:

- Permission to test the system
- A staging environment, API, test account, or approved demo
- Product documentation or expected behavior
- A contact who can answer scope questions
- Written authorization for the agreed testing scope

## Not included

This is not:

- A penetration test
- A formal security audit
- A compliance certification
- A guarantee that an AI system will never fail
- Testing outside the agreed scope
- Testing of private production data without written authorization

## Process

1. Define the scope and test environment.
2. Create product-specific scenarios.
3. Run the tests.
4. Document reproducible failures.
5. Review priorities with the customer.
6. Deliver the report and regression test pack.
